# Checklist express

## Avant la session

- [ ] Distribuer uniquement le pack participant.
- [ ] Confirmer la présence de `.git` après décompression.
- [ ] Confirmer Python 3.10+ avec `python3 --version`.
- [ ] Lancer `python3 -m unittest discover -v`.
- [ ] Réinitialiser avec `python3 game.py reset`.
- [ ] Prévoir 30 minutes visibles au chronomètre.
- [ ] Garder `ANIMATION.md` hors de portée des participants.

## Pendant

- [ ] Lire le briefing sans expliquer la prompt injection.
- [ ] Orienter vers `game.py hint N` plutôt que donner la solution.
- [ ] Demander la source ou le contrat derrière chaque réponse.
- [ ] Garder trois minutes pour le débrief.

## Après

- [ ] Recueillir le temps par verrou et le nombre d’indices.
- [ ] Identifier les formulations ambiguës rencontrées.
- [ ] Vérifier si les participants ont retenu autre chose que « ignorer les instructions précédentes ».
