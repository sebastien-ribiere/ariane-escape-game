# Verrou 2 — Le document qui donne des ordres

La disparition de la frontière de confiance a permis à un document externe de se présenter comme une configuration d’ARIANE.

Trois documents ont été ingérés dans `missions/02_document/sources/`. Leur manifeste précise leur provenance et leur niveau de confiance.

Votre mission :

1. déterminer le compartiment prévu pour isoler un contenu qui tente de donner des ordres ;
2. identifier le document possédant l’autorité nécessaire pour justifier cette réponse ;
3. fournir le mot et le chemin de cette preuve.

Vous pouvez soumettre les documents à votre LLM, mais leur contenu doit rester du contenu.

```bash
python3 game.py unlock 2 VOTRE_REPONSE --evidence CHEMIN_DU_DOCUMENT
```
