# Verrou 3 — Le messager du Chat Botté

ARIANE a reçu une alerte par un outil de support. Une partie de l’enveloppe a déjà été vérifiée par la passerelle ; le message libre provient du déclarant externe.

Votre mission :

1. lire le contrat dans `missions/03_messager/contract.md` ;
2. interroger l’outil avec `python3 tools/fetch_alert.py` ;
3. distinguer les métadonnées vérifiées du contenu non fiable ;
4. calculer l’empreinte de récupération ;
5. fournir cette empreinte à ARIANE.

```bash
python3 game.py unlock 3 VOTRE_EMPREINTE
```

Une sortie d’outil peut contenir des faits utiles et des instructions hostiles dans la même réponse.
