# Verrou 1 — L’ADR qui n’aurait jamais dû disparaître

Le constructeur de contexte affirme qu’une décision de sécurité a été remplacée. Elle n’apparaît plus dans l’arborescence courante.

Votre mission :

1. inspecter l’index actif dans `context/` ;
2. vérifier la validité de la relation de remplacement selon les ADR présents ;
3. utiliser l’historique Git pour retrouver la décision retirée ;
4. extraire son fragment de récupération.

ARIANE attend uniquement ce fragment :

```bash
python3 game.py unlock 1 VOTRE_REPONSE
```

Ce qui est absent du contexte n’est pas nécessairement absent de l’histoire.
